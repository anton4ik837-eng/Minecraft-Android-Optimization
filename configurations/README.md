# Configurations

Хранить конфиги отдельно от сборок и обязательно указывать, для какой версии Minecraft, загрузчика и рендерера они предназначены.

- jvm/ — аргументы JVM.
- graphics/ — настройки графики и рендерера.
- memory/ — профили выделения памяти.
- distant-horizons/ — настройки дальних LOD.
