# Builds

Готовые импортируемые сборки Zalith Launcher. Большие архивы лучше публиковать в GitHub Releases, а здесь хранить манифесты, контрольные суммы и инструкции.

- stable/ — проверенные сборки.
- experimental/ — текущие эксперименты.
- archived/ — старые версии и неудачные/устаревшие варианты.

Каждая сборка должна иметь отдельную папку с `manifest.json`, README и checksum-файлом.
