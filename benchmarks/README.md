# Benchmark protocol

## Test record
- Test ID:
- Date/time:
- Device / Android build:
- Zalith version:
- Minecraft version:
- Loader + version:
- Renderer/backend + version:
- Modpack/build ID:
- World/seed and coordinates:
- Resolution / render distance / simulation distance:
- Shader/resource pack:
- Battery level / power mode:
- Start temperature / end temperature:

## Measurements
- Warm-up duration:
- Capture duration:
- Average FPS:
- 1% low FPS:
- Frame-time notes:
- Chunk generation/loading observations:
- RAM usage:
- Thermal throttling:
- Crashes/artifacts:

## Reproducibility
Attach launcher, Minecraft and renderer logs. Repeat the same scenario at least three times where practical. Record raw results; do not report a single peak FPS as sustained performance.
