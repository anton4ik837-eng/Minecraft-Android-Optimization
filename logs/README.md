# Logs

Папки: launcher/, minecraft/, renderer/, crashes/, benchmarks/.

Именование: `YYYY-MM-DD_<TEST-ID>_<component>.log`.

Перед публикацией удалять токены, приватные URL, имена пользователей/устройств и другие личные данные. Логи должны сопровождаться кратким описанием шага, на котором они получены.
