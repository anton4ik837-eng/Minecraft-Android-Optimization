# Renderers

Здесь ведётся учёт графических бэкендов и драйверов, доступных в конкретной версии Zalith Launcher. Наличие папки не означает поддержку или совместимость.

Для каждого теста фиксировать:
- точное название и версию рендерера;
- источник/версию сборки и необходимые библиотеки;
- GPU-драйвер и Vulkan/OpenGL capabilities, если доступны;
- параметры запуска;
- Minecraft version, loader, моды;
- лог запуска и результат.

Статусы и ограничения — в [compatibility.md](compatibility.md).
